# Personal-Scriptbank

এই রিপোজিটরিটিতে আমার ব্যক্তিগত অটোমেশন স্ক্রিপ্ট এবং টুলগুলো সংরক্ষিত আছে। সিএসই (CSE) শিক্ষার্থী হিসেবে আমার দৈনন্দিন ল্যাব ওয়ার্ক এবং একাডেমিক প্রোডাক্টিভিটি বাড়ানোর লক্ষ্যে এই স্ক্রিপ্টগুলো তৈরি করা হয়েছে।

## বিষয়বস্তু (Contents)
- **Fast C/C++ Generator (`fast_create.py`):** একটি পাইথন স্ক্রিপ্ট যা দ্রুত ল্যাব ফাইল স্ট্রাকচার তৈরি করতে এবং প্যারালাল প্রসেসিংয়ের মাধ্যমে সময় বাঁচাতে সাহায্য করে।
- **Media Backup Utility (`media_backup.py`):** মিডিয়া ফাইলগুলোকে জিপ আকারে ব্যাকআপ নেওয়া এবং এমডি৫ (MD5) হ্যাশিংয়ের মাধ্যমে সেগুলোর ইনটিগ্রিটি চেক করার টুল।

## টেকনিক্যাল স্পেসিফিকেশন
- **Language:** Python 3
- **Dependencies:** 
  - `tqdm` (প্রগ্রেস বার ভিজ্যুয়ালাইজেশনের জন্য)
  - `pathlib` (বিল্ট-ইন পাথ ম্যানেজমেন্টের জন্য)
  - `concurrent.futures` (মাল্টি-প্রসেসিংয়ের জন্য)
  - `hashlib` (ডেটা ইনটিগ্রিটি চেকের জন্য)

## ব্যবহারের নিয়ম (Usage)
টার্মিনালে নিচের কমান্ডটি অনুসরণ করুন:

**ফাস্ট ফাইল জেনারেটরের জন্য:**
```bash
python3 fast_create.py <filename> <count> -d <directory>
```
মিডিয়া ব্যাকআপের জন্য:
```bash
python3 media_backup.py
```
